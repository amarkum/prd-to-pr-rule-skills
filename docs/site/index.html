From a Confluence PRD to a reviewed pull request, in one loop

The standard takes a PRD through six stages across the Airflow data repo, the micro-frontends and the frontend shell. Each stage commits a file that the next stage reads. People decide at the gates, and hooks enforce the gates as code, so they hold even when a prompt is ignored.

The six stages

The stages follow Anthropic's AI-native SDLC playbook. Select a stage to see what it commits, who decides, how the decision is enforced and how you measure it.
