# stack-frontend: React frontend pack

Teaches the AI SDLC builder this organisation's React and TypeScript conventions. The `frontend-feature` skill activates
on `src/`, `e2e/` and `tests/` files. It covers every UI state, accessibility, typed API access, flags, analytics and
security, plus evidence-grade tests: Testing Library per AC with MSW at the network boundary, and Playwright tests named
by AC with screenshots, traces and axe scans. JUnit output feeds the coverage checker.
Install with `/plugin install stack-frontend@ai-sdlc`. Owned by the Web Platform Guild.
